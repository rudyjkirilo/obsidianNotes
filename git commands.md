- `git init`- adding git in current directory
- `git add` - start tracking files, -A to track all files
- `git commit` - report tracked files, -m to describe the commit "Initial commit" is a universal naming convention for the first commit
- `git branch` - create a branch, -M to force rename a branch, 'main' is a universal naming convention for the first branch 
- `git remote add origin` - `remote` tell git to work with remote repository, `add` to add the repository URL, `origin` to alias the remote repository
- `git push` - pushing commits to remote repository, `-u` to synchronize with remote branch, where first parameter is a repository alias and second parameter is a name of the branch
- `git rm`  - to remove files from git and the disk itself, `-r` to remove a directory 
- `git status`  -  to show the status of the files (untracked, added, modified, removed, etc.)

1. `git init`
2. `git add`
3. `git commit`
4. `git branch`
5. `git remote add origin`
6. `git push`
